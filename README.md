# DevKit 🛠️

DevKit is a simple collection of useful web tools built for developers, students, and anyone who needs quick everyday utilities in one place.

Instead of opening a different website for every small task, DevKit brings several tools together in a clean and responsive interface.

### 🧰 Available Tools

* **JSON Formatter** — Format, validate, and minify JSON.
* **Text Toolkit** — Count, transform, and clean text.
* **Color Converter** — Convert between HEX, RGB, and HSL.
* **Password Generator** — Generate strong customizable passwords.

### 💻 Built With

* HTML
* CSS
* JavaScript

The project is completely browser-based, so the tools work directly in the browser without requiring installation.

### ✨ What I Focused On

I built DevKit with a focus on keeping things **simple, fast, responsive, and easy to use**. The project also includes small animations, responsive layouts, and basic SEO so it feels like a real usable product rather than just a collection of separate tools.
