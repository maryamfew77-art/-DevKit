# DevKit 🛠️

🌐 **Live Demo:** https://dekit-maryam-ayubs-projects.vercel.app/

DevKit is a simple collection of useful web tools built for developers, students, and anyone who needs quick everyday utilities in one place.

Instead of opening a different website for every small task, DevKit brings several tools together in a clean and responsive interface.

## Features

DevKit includes the following tools:

1. **JSON Formatter** – Format and organize JSON data.
2. **Text Toolkit** – Perform common text operations.
3. **Color Converter** – Convert between color formats.
4. **Password Generator** – Generate customizable passwords.
5. **Base64 Encoder/Decoder** – Encode and decode Base64 text.
6. **QR Code Generator** – Generate and download QR codes.
7. **UUID Generator** – Generate unique identifiers.
8. **Timestamp Converter** – Convert timestamps and dates.
9. **JSON to CSV Converter** – Convert JSON arrays into CSV files.
10. **HTML & CSS Formatter** – Format HTML and CSS code.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser APIs
- QRCode.js library for QR code generation
